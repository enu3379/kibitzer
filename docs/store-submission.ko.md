# Chrome Web Store 제출 킷 (베타 · 비공개 unlisted)

CWS 대시보드의 각 폼에 그대로 붙여 넣을 수 있게 정리한 제출 자료. 스크린샷/프로모 타일은 별도 작업(아래 체크리스트).

## 리스팅 기본

- **이름**: Kibitzer — 몰입 훈수꾼
- **카테고리**: 생산성 (Productivity)
- **언어**: 한국어
- **요약(짧은 설명, ≤132자)**: 목표를 선언하면 브라우징을 조용히 지켜보다, 딴짓이 쌓일 때만 슬쩍 훈수를 두는 로컬 집중 도우미. 서버 없음 — 기본 판정도 기록도 내 브라우저 안에서만.

## 상세 설명 (스토어 본문)

집중이 필요할 때, Kibitzer에게 목표 한 줄만 알려주세요.

"논문 정리", "분기 보고서 작성", "파이썬 공부" — 목표를 선언하면 Kibitzer가 브라우징 흐름을 조용히 지켜봅니다. 잠깐 다른 페이지를 열었다고 바로 잔소리하지 않습니다. 몰입 게이지(S)가 차오르고 닳는 걸 지켜보다가, 딴짓이 충분히 쌓였을 때만 화면 구석에서 슬쩍 한마디 건넵니다. 차단하지 않고, 훈수만 둡니다.

**이런 게 다릅니다**

- 🕐 클릭 수가 아니라 체류 시간으로 판단합니다. 5초 스쳐 간 페이지는 세지 않습니다.
- 🎭 페르소나를 고르세요. 영국 집사부터 츤데레, 내비게이션, 다큐 내레이터까지 — 잔소리도 취향껏.
- 📊 세션이 끝나면 몰입 요약을 받아보세요. 어디에 시간이 샜는지 한눈에 보입니다.
- 🌙 시간 예산을 넘기면 해시계 위로 달이 뜹니다.

**프라이버시가 기본값입니다**

- 서버가 없습니다. 판정·기록·학습 전부 브라우저 안에서만 이뤄집니다.
- 기본 판정(Tier 0)은 내장 로컬 AI 모델이 수행합니다 — 아무것도 전송되지 않습니다.
- 더 똑똑한 판정을 원하면 본인의 LLM API 키(Ollama Cloud, Gemini, OpenAI 등 7종)를 등록할 수 있고, 그때도 페이지 제목·발췌 같은 최소 정보만 선택한 제공자에게 갑니다. 원시 URL은 절대 보내지 않습니다.
- 은행·의료·정부·웹메일 등 민감한 사이트는 아예 관측하지 않습니다.
- 시크릿 창에서는 동작하지 않습니다.

자세한 내용: 개인정보 처리방침(리스팅의 정책 URL 참조)

## 단일 목적 선언 (Single purpose)

사용자가 선언한 목표 대비 브라우징 이탈을 감지해 알려주는 집중 유지 도우미. 모든 권한과 기능이 이 단일 목적(관측 → 판정 → 훈수)에만 쓰인다.

## 권한 정당화 (심사 폼 문항별)

| 권한 | 정당화 |
|---|---|
| `tabs` | 활성 탭의 제목·호스트를 읽어 선언된 목표와 비교 판정한다(tabs.query/get/onUpdated/onActivated). 제목 판정이 제품의 핵심 입력이다. |
| `webNavigation` | SPA(유튜브 등)의 라우트 변경은 페이지 로드 이벤트 없이 일어나므로 onHistoryStateUpdated로 감지한다. |
| `scripting` | ① 이탈이 누적됐을 때만 판정 직전에 페이지 본문 발췌(≤3,500자)를 읽고, ② 화면 구석에 비차단 훈수 토스트를 그린다. 둘 다 사용자 제스처 없이 자동 실행되어야 하므로 activeTab으로 대체 불가. |
| `host_permissions` (`http/https *:/*`) | 어떤 사이트에서든 위 관측·토스트가 동작해야 하는 제품 본질. 민감 도메인 내장 차단 목록으로 원천 제외를 병행한다. |
| `alarms` | 1분 하트비트로 체류 시간 기반 몰입 게이지를 갱신한다(MV3 서비스 워커는 타이머를 유지할 수 없음). |
| `storage` | 목표·설정·API 키·게이지 상태의 로컬 저장. |
| `idle` | 자리 비움을 감지해 부재 중 게이지 증감을 멈춘다. |
| `downloads` | 사용자가 설정에서 직접 실행하는 진단 로그/이벤트 JSONL 내보내기 전용. |
| `offscreen` | 훈수 알림 차임 오디오 재생(MV3 워커는 오디오 재생 불가). |
| `notifications` | Chrome이 포커스되고 사용자가 활성 상태지만 현재 페이지에 인페이지 토스트를 주입할 수 없을 때(Chrome 내부 페이지·PDF 등) 같은 훈수를 OS 알림으로 전달한다. 설정한 AI 제공자 오류로 훈수가 보류됐을 때도 최대 6시간에 한 번 상태 안내에 사용한다. Chrome이 포커스 밖이거나 사용자가 자리를 비운 동안에는 어느 알림도 표시하지 않는다. |

원격 코드 없음(esbuild 정적 번들, CSP `script-src 'self' 'wasm-unsafe-eval'` — WASM은 동봉된 로컬 임베딩 모델용). `incognito: not_allowed`.

## 데이터 공개 폼 (Privacy practices)

- **수집하는 데이터**: "웹 사이트 콘텐츠(Website content)" — 페이지 제목·호스트, (Tier-2 시) 본문 발췌 ≤3,000자. **사용자가 본인 API 키를 등록한 경우에만**, 사용자가 선택한 LLM 제공자에게 판정 목적으로 전송. 개발자는 어떤 데이터도 수신하지 않음(서버 없음).
- **판매/제3자 공유 아님**, 신용도 판단·대출 목적 아님, 핵심 기능 외 목적 없음 — 모두 해당 없음 체크.
- **정책 URL**: `docs/privacy-policy.ko.md`의 공개 호스팅 URL (호스팅 방식 확정 후 기입)
