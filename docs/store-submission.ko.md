# Chrome Web Store 제출 킷

CWS 대시보드의 각 폼에 그대로 붙여 넣을 수 있게 정리한 리스팅 자료. 게시된 버전(v0.3.0) 기준으로 쓴다 —
`dev`에만 있는 기능은 본문에 넣지 말고 맨 아래 "다음 릴리스에 추가할 문단"에 모아 둔다.

## 리스팅 기본

- **이름**: Kibitzer — 몰입 훈수꾼
- **카테고리**: 생산성 (Productivity)
- **언어**: 한국어
- **요약(짧은 설명, ≤132자)**: 목표를 선언하면 브라우징을 조용히 지켜보다, 딴짓이 쌓일 때만 슬쩍 훈수를 두는 몰입 도우미. 기본 판정도 기록도 내 브라우저 안에서만.

  (76자. `manifest.json`의 `description`과 같은 문자열을 쓴다.)

## 상세 설명 (스토어 본문)

집중이 필요할 때, Kibitzer에게 목표 한 줄만 알려주세요.

"졸업논문 관련연구 정리", "분기 보고서 작성", "선형대수 3장 문제풀이" — 목표를 선언하면 Kibitzer가 브라우징 흐름을 조용히 지켜봅니다. 잠깐 다른 페이지를 열었다고 바로 잔소리하지 않습니다. 몰입 게이지가 차오르고 닳는 걸 지켜보다가, 딴짓이 충분히 쌓였을 때만 화면 구석에서 슬쩍 한마디 건넵니다. 차단하지 않고, 훈수만 둡니다.

**이렇게 동작합니다**

1. 툴바 팝업에 목표 한 줄을 적고 시작합니다. 쓸 수 있는 시간을 함께 적어 두면 시간 예산으로 잡힙니다.
2. Kibitzer는 지금 보고 있는 탭의 제목과 도메인만 보고 목표와 관련 있는지 판정합니다. 5초 이상 머문 페이지만 셉니다 — 스쳐 지나간 탭은 아예 기록되지 않습니다.
3. 목표에서 벗어난 페이지에 머무는 동안 몰입 게이지가 내려갑니다. 충분히 내려갔을 때 한 번, 페이지 구석에 작은 말풍선이 뜹니다. 클릭 한 번이면 사라지고, "5분만"이나 "30분 조용히"로 미뤄 둘 수도 있습니다.
4. 세션을 끝내면 요약이 뜹니다. 유효 페이지 비율, 실제로 목표에 쓴 시간, 받은 훈수 횟수, 가장 오래 머문 페이지가 한 화면에 정리됩니다.

**이런 게 다릅니다**

- 클릭 수가 아니라 머문 시간으로 판단합니다. 5초 스쳐 간 페이지는 세지 않고, 오래 붙잡힌 딴짓일수록 게이지가 많이 깎입니다.
- 몰입 게이지는 0에서 100까지 움직이고 집중(66 이상) · 흔들림 · 이탈(33 미만) 세 구간으로 색이 바뀝니다. 툴바 아이콘의 점 색만 봐도 지금 어느 구간인지 알 수 있습니다.
- 시간 예산을 적어 두면 팝업의 해시계 위로 해가 지나갑니다. 예산을 넘기면 해 대신 달이 떠서 초과 시간을 알려줍니다.
- 말투를 고를 수 있습니다. 기본 네 가지(내비게이션 · 츤데레 · 다큐 내레이터 · 영국 집사)에 더해, 아직 다듬는 중인 여섯 가지가 실험실에 들어 있습니다. 카드를 고르면 그 말투가 어떻게 말하는지 바로 한 줄 들려줍니다.
- 훈수에 답할 수 있습니다. "목표와 관련 있어요"를 누르면 오판으로 기록되어 다음 판정이 그만큼 조심스러워집니다.
- 보고 싶지 않은 사이트는 감시 제외 목록에, 늘 목표와 관련 있는 사이트는 항상 OK 목록에 적어 두세요.

**프라이버시를 지킵니다**

- 개발자는 아무런 데이터도 수집하지 않습니다.
- 기본 판정은 확장과 함께 설치되는 한국어·영어 임베딩 모델이 브라우저 안에서 수행합니다. 기본 판정만 쓰는 동안에는 아무 정보도 밖으로 나가지 않습니다.
- 더 정확한 판정과 자연스러운 훈수 문장을 원하면 본인의 LLM API 키를 등록할 수 있습니다 (Ollama Cloud · Gemini · OpenAI · Claude · DeepSeek · OpenRouter · Kimi). 이때 선택한 AI 서비스 제공자에게 가는 것은 페이지 제목, 도메인, 본문 발췌(최대 3,000자)뿐입니다. 경로와 검색어가 포함된 전체 주소는 보내지 않습니다.
- 은행·결제·의료·정부·웹메일 같은 민감한 사이트는 목록에 넣지 않아도 처음부터 관측하지 않습니다.
- 시크릿 창에서는 동작하지 않습니다.
- 판정 기록과 세션 이력은 브라우저 안에만 남고, 설정의 데이터 탭에서 한 번에 지울 수 있습니다.

**설치 전에 알아두세요**

- 설치 용량이 약 88MB입니다. 인터넷 없이도 판정할 수 있게 임베딩 모델을 함께 담았기 때문입니다.
- Chrome 123 이상이 필요합니다.
- 화면과 훈수 문장 모두 한국어입니다.
- LLM API 연결은 선택입니다. 키를 넣지 않아도 로컬 판정만으로 동작합니다.

의견과 버그 제보는 GitHub 저장소의 Issues로 보내 주세요.

캡처 호스트가 다크 모드면 옵션 페이지가 통째로 어두워지므로, 스텁에서 라이트 토큰 값을 캐스케이드 마지막에 다시 선언해야 한다.

3번만 예외다 — 긴 MVP 제목이 하이라이트 카드를 밀어내던 실제 팝업 버그(`.hlc`에 `min-width: 0`이 없어
그리드 트랙이 `.hn`의 nowrap 최소 너비를 따라가던 문제)를 같이 고쳤으므로, 그 한 줄을 적용한 팝업에서 다시 캡처했다.

4·5번은 게시 버전에서 두 가지가 앞서 있다. 머리말은 PR #223에서 고친 문구(`목표 선언은 툴바 팝업에서.`)를 썼고 —
v0.3.0에는 삭제된 기능을 가리키는 `훈수 응답은` 이 남아 있지만 다음 릴리스에서 사라질 문구를 스토어 이미지에 박아 둘 이유가 없다 —
머리말 옆 로고는 툴바 아이콘과 명암이 반대(흰 얼굴·검은 눈)이던 것을 아이콘 비율로 맞춘 새 SVG로 바꿔서 찍었다.

## 단일 목적 선언 (Single purpose)

사용자가 선언한 목표 대비 브라우징 이탈을 감지해 알려주는 집중 유지 도우미. 모든 권한과 기능이 이 단일 목적(관측 → 판정 → 훈수)에만 쓰인다.

## 권한 정당화 (심사 폼 문항별)

| 권한 | 정당화 |
|---|---|
| `tabs` | 활성 탭의 제목·호스트를 읽어 선언된 목표와 비교 판정한다(tabs.query/get/onUpdated/onActivated). 제목 판정이 제품의 핵심 입력이다. |
| `webNavigation` | SPA(유튜브 등)의 라우트 변경은 페이지 로드 이벤트 없이 일어나므로 onHistoryStateUpdated로 감지한다. |
| `scripting` | ① 이탈이 누적됐을 때만 판정 직전에 페이지 본문 발췌(추출 상한 3,500자 → 전송 시 3,000자로 재정제)를 읽고, ② 화면 구석에 비차단 훈수 토스트를 그린다. 둘 다 사용자 제스처 없이 자동 실행되어야 하므로 activeTab으로 대체 불가. |
| `host_permissions` (`http/https *:/*`) | 어떤 사이트에서든 위 관측·토스트가 동작해야 하는 제품 본질. 민감 도메인 내장 차단 목록으로 원천 제외를 병행한다. |
| `alarms` | 1분 하트비트로 체류 시간 기반 몰입 게이지를 갱신한다(MV3 서비스 워커는 타이머를 유지할 수 없음). |
| `storage` | 목표·설정·API 키·게이지 상태의 로컬 저장. |
| `idle` | 자리 비움을 감지해 부재 중 게이지 증감을 멈춘다. |
| `downloads` | 사용자가 설정에서 직접 실행하는 진단 로그/이벤트 JSONL 내보내기 전용. |
| `offscreen` | 훈수 알림 차임 오디오 재생(MV3 워커는 오디오 재생 불가). |
| `notifications` | 브라우저가 포커스 밖일 때 토스트 대신 OS 알림으로 전달하는 폴백. |

원격 코드 없음(esbuild 정적 번들, CSP `script-src 'self' 'wasm-unsafe-eval'` — WASM은 동봉된 로컬 임베딩 모델용). `incognito: not_allowed`.

## 데이터 공개 폼 (Privacy practices)

- **수집하는 데이터**: "웹 사이트 콘텐츠(Website content)" — 페이지 제목·호스트, (Tier-2 시) 본문 발췌 ≤3,000자. **사용자가 본인 API 키를 등록한 경우에만**, 사용자가 선택한 LLM 제공자에게 판정 목적으로 전송. 개발자는 어떤 데이터도 수신하지 않음(서버 없음).
- **판매/제3자 공유 아님**, 신용도 판단·대출 목적 아님, 핵심 기능 외 목적 없음 — 모두 해당 없음 체크.
- **정책 URL**: https://github.com/enu3379/kibitzer/blob/main/docs/privacy-policy.ko.md
  (저장소가 공개라 별도 호스팅 없이 접근 가능하다. 대시보드에도 같은 URL을 입력한다.)

## 다음 릴리스에 추가할 문단

v0.3.0에는 없고 `dev`에만 있는 기능. 다음 버전을 올릴 때 본문에 합칠 것.

- **재시작 시 세션 자동 유지** — 크롬을 완전히 껐다가 5분 안에 다시 켜면 진행 중이던 세션을 그대로 이어간다. 꺼 두어도 종료하지 않은 세션은 남아 있어 팝업에서 직접 이어갈 수 있다.
- **로컬 PDF 제목 관측** — Chrome에서 연 PDF의 문서 제목(없으면 파일명)을 판정·기록에 쓴다. 파일 경로와 PDF 본문은 저장·전송하지 않는다.
- **음성으로 읽기(TTS) 제거** — 설정에서 빠졌다. 본문에 넣지 말 것.
