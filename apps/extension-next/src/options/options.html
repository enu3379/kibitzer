모델 지정
Tier 1 · 빠른 판정어떤 데이터가 전송되나요?빠른 목표 이탈 판정을 위해 목표, 현재 페이지의 제목·호스트, 최근 최대 20개 페이지의 제목·판정이 전송됩니다. 페이지 본문은 전송하지 않습니다. 한눈판 듯하면 훑어보는 저비용 모델
Tier 2 · 정밀 판정어떤 데이터가 전송되나요?더 정확한 목표 이탈 판정과 훈수 메시지 생성을 위해 목표, 현재 페이지의 제목·호스트·본문 최대 3,000자, 최근 최대 20개 페이지의 제목·판정이 전송됩니다. 세션 요약에는 체류시간 상위 최대 5개 페이지 정보가 사용됩니다. 내용을 정독하고 훈수를 쓰는 모델
